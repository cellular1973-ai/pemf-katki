# Düzeltme ve kalibrasyon önerileri

Her öneri kendi klasöründe:

```
oneriler/
└── 2026-10-14-yesil-halka-capi/
    ├── README.md          # sablonlar/duzeltme-kalibrasyon.md'den
    ├── veri/
    │   ├── ham/           # ölçtüğünüz gibi
    │   └── islenmis/      # işlediyseniz (nasıl işlendiği README'de)
    └── analiz.py          # isteğe bağlı: hesaplamanız (ya da analiz.ipynb)
```

Klasör adı: `<YYYY-AA-GG>-<kisa-konu>` (küçük harf, Türkçe karakter yok, kelimeler tireyle). Önce bir **Düzeltme / kalibrasyon** konusu
(issue) açın, sonra bu klasörle PR gönderin; PR açıklamasına `Kapatır #<konu>` yazın. Ayrıntı: `OGRENCI-REHBERI.md` §6.
